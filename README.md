# zqq-015 · 成语字源与语义DNA图谱

纯前端成语字源考据与语义拓扑分析系统。用户输入任意成语，系统拆解为四字金石甲骨字形溯源、典故出处时间轴与原文引证、语义流变路径，并测算生成该成语的"语义DNA"（本义/引申义/比喻义占比环形图及核心义原），支持任意两个成语的语义亲缘度交叉比对演算。

## 架构说明（分层架构：核心层 / 端口层 / 适配器层）

- `src/core`：领域模型（`OracleChar`、`AllusionSource`、`SemanticEvolutionStep`、`SemanticDNA`、`IdiomProfile`、`KinshipResult`）与欧氏DNA几何距离、义原Jaccard相似度算法。
- `src/ports`：端口层契约（`IdiomRepositoryPort` 典籍成语检索端口、`KinshipPort` 亲缘度比对端口、`StudyStatePort` 学习状态持久化端口、`ContentCatalogPort` 内容目录端口）。
- `src/adapters`：适配器层（内置甲骨文字典与通用汉字语义生成适配器、亲缘比对分析适配器、localStorage 学习状态适配器、内容目录适配器）。
- `src/ui`：原生 CSS 宣纸墨韵古典视觉呈现层，包含金石甲骨卡片、历史时间轴、语义DNA甜甜圈图表、双词亲缘竞技场与一周学习队列。

## 学习计划生成器（📅 学习计划）

依据 **收藏、熟练度与遗忘间隔** 生成一周学习队列，核心机制：

- **排序（紧迫度）**：逾期 > 今日到期 > 新内容 > 未来到期；逾期天数越多、熟练度越低越靠前。评分采用 SM-2 风格间隔算法（again/hard/good/easy 调整熟练度、ease 与下次到期日）。
- **一周队列冻结**：周一对每人生成一次有序快照（`frozenWeeks`），按名次轮转铺到周一至周日（负载均衡）。周内即使完成复习、熟练度变化或取消收藏，**跨天刷新顺序都保持不变**；新的一周才按最新状态重新冻结。
- **完成记录可回滚**：所有写操作（复习完成、收藏 / 取消收藏）以事件流水追加，事件携带逆操作快照，支持撤销最后一条或乱序回滚任意一条（进度、收藏及其下标都精确还原）。
- **冷启动**：没有任何收藏时，自动用预置经典成语作为种子目录填充本周队列（标记"推荐"），新用户打开即有内容可学；在单词页 ★ 收藏后，下一周完全按个人收藏排期。
- 状态通过 `localStorage` 持久化，损坏数据自动降级为空状态；日期以 `YYYY-MM-DD` 本地日期键 + 可注入 `Clock` 计算，测试可模拟跨天。

核心纯函数位于 `src/core/study-scheduler.ts`（排序、冻结、回滚均为纯函数，不依赖 DOM），编排在 `src/core/study-service.ts`。

## 测试

```bash
npm test
```

使用 Node 内置 test runner（无需额外依赖）：32 个用例覆盖日期工具、间隔算法、紧迫度排序、冷启动、周队列冻结 / 跨天稳定、跨周重排、事件回滚（含乱序与收藏下标还原）、持久化降级等。
