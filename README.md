# zqq-015 · 成语字源与语义DNA图谱 + 学习计划生成器

纯前端应用，包含两大模块：

1. **成语字源考据与语义拓扑分析**：输入任意成语，系统拆解为四字金石甲骨字形溯源、典故出处时间轴与原文引证、语义流变路径，并测算生成该成语的"语义DNA"（本义/引申义/比喻义占比环形图及核心义原），支持任意两个成语的语义亲缘度交叉比对演算。

2. **学习计划生成器**：依据收藏、熟练度与遗忘间隔（SM-2 模型）生成一周学习队列，完成记录可回滚，跨天刷新顺序稳定，支持无收藏内容的冷启动引导。

## 架构说明（分层架构：核心层 / 端口层 / 适配器层）

- `src/core`：领域模型（`OracleChar`、`AllusionSource`、`SemanticEvolutionStep`、`SemanticDNA`、`IdiomProfile`、`KinshipResult`、`StudyItem`、`ReviewState`、`CompletionRecord`、`DayQueue`）、欧氏DNA几何距离、义原Jaccard相似度算法、SM-2 遗忘间隔调度算法、一周学习队列生成器（确定性哈希排序）。
- `src/ports`：端口层契约（`IdiomRepositoryPort` 典籍成语检索端口、`KinshipPort` 亲缘度比对端口、`StudyStoragePort` 学习计划存储端口）。
- `src/adapters`：适配器层（内置甲骨文字典与通用汉字语义生成适配器、亲缘比对分析适配器、localStorage 持久化与完成记录回滚适配器）。
- `src/ui`：原生 CSS 宣纸墨韵古典视觉呈现层，包含金石甲骨卡片、历史时间轴、语义DNA甜甜圈图表、双词亲缘竞技场与一周学习队列面板。

## 学习计划生成器核心特性

- **一周队列**：7 天 × 每天 5 条学习条目，依据优先级（收藏 > 到期/逾期 > 低熟练度 > 新条目）智能排序。
- **遗忘间隔**：基于 SM-2 算法，根据记忆质量（忘记/模糊/掌握）动态调整复习间隔（1 天 → 6 天 → 递增）。
- **可回滚**：每次完成记录保存前后状态快照，支持撤销最近完成，恢复至完成前的熟练度与复习状态。
- **顺序稳定**：采用确定性哈希扰动（`hash(dayKey + itemId)`），同一天内多次刷新队列顺序不变，跨天自然变化。
- **冷启动**：无收藏内容时自动展示入门包（4 个推荐成语），一键添加收藏即可生成个性化队列。
